# Masjid Musab bin Umair — Organization Governance

Organization profile, community guidelines, and default issue/PR templates for **Masjid Musab bin Umair (West Forsyth Islamic Center)** in Cumming, Georgia.

## Included Files

| File / Folder | Purpose |
| :--- | :--- |
| [`profile/README.md`](./profile/README.md) | Public landing page displayed at [github.com/masjidmusab](https://github.com/masjidmusab) |
| [`CONTRIBUTING.md`](./CONTRIBUTING.md) | Branch naming, commit conventions, and pull request workflow |
| [`CODE_OF_CONDUCT.md`](./CODE_OF_CONDUCT.md) | Community standards and Islamic *Adab* for contributors |
| [`SECURITY.md`](./SECURITY.md) | Private vulnerability reporting instructions (`security@masjidmusab.com`) |

| [`PULL_REQUEST_TEMPLATE.md`](./PULL_REQUEST_TEMPLATE.md) | Default pull request checklist across all org repos |
